1. Core Architecture Breakdown

The Mental Model Shift

If you are transitioning from Virtual DOM libraries (like React or Vue):

  • No Virtual DOM: Angular compiles HTML templates ahead of time (AOT) via the Ivy compiler directly into monomorphic DOM manipulation instructions. Updates bypass tree diffing.
  • Static vs. Dynamic Execution: Instead of components executing from top-to-bottom on every state change, Angular components are class instances. Reactivity is isolated to specific bindings or Signal updates.
  • Hierarchical Separation: Business logic is strongly decoupled from presentation layout. Services manage network state, components present UI, and Dependency Injection couples them together at runtime.

Modern Angular Building Blocks

1. Standalone Components

Angular 17+ defaults to Standalone components. The legacy boilerplate of NgModule has been removed. Standalone components declare their dependencies directly in their component metadata:

@Component({
  selector: 'app-user-card',
  standalone: true,
  imports: [CommonModule, FocusHighlightDirective],
  template: `
    <div class="card" [class.active]="isActive">
      <h3>{{ name }}</h3>
      <button (click)="select.emit(name)">Select</button>
    </div>
  `
})
export class UserCardComponent {
  @Input({ required: true }) name!: string;
  @Input({ transform: booleanAttribute }) isActive = false;
  @Output() select = new EventEmitter<string>();
}

Architectural Pattern: Deferred Loading

Use the compiler-level @defer block to automatically split bundle chunks and lazy-load components based on interaction parameters (e.g. viewport intersection, user interaction, idle browser status).

2. Directives & Pipes

Directives extend HTML element behavior (attributes vs structural transformations). Pipes perform pure data transformation formatting in templates, caching returns by reference inputs (pure mode).

Dependency Injection (DI) System

Angular features a powerful, hierarchical Dependency Injection system. The compiler resolves dependencies by searching upwards through the injection scope tree:

  1. Element Injector: Declared inside component/directive providers: [...]. Scoped locally to that component tree instance.
  2. Environment Injector: Set up via app bootstrap configurations or route declarations.
  3. Root Injector: Declared globally via @Injectable({ providedIn: 'root' }).

Modern Angular relies on the inject() function over traditional constructor injection. It increases Type inference stability and works seamlessly in functional contexts.

Reactivity: Zone.js vs. Signals

Historically, Angular used Zone.js to monkey-patch async APIs and trigger dirty checking globally. Angular 17/18+ introduces fine-grained reactive Signals, tracking exactly where values are read in the DOM template. This enables the complete removal of Zone.js (Zoneless Angular) for maximized performance.

2. Creating a Project from Scratch

CLI Installation & Project Bootstrapping

Install the Angular command line interface globally or execute directly via NPX:

npm install -g @angular/cli
ng new senior-app --style=scss --routing --standalone --strict --package-manager=npm

Configuration Implementation

In standalone architectures, provider configurations are injected globally inside app.config.ts:

// src/app/app.config.ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideZoneChangeDetection({ eventCoalescing: true }),
    provideRouter(routes, withComponentInputBinding()),
    provideHttpClient()
  ]
};

3. Essential Core Features (The 80/20 Toolkit)

Strictly Typed Forms

Reactive Forms manage form fields as immutable state streams. Leverage NonNullableFormBuilder to ensure inputs never default back to null properties:

@Component({
  standalone: true,
  imports: [ReactiveFormsModule, CommonModule],
  template: `
    <form [formGroup]="userForm" (ngSubmit)="submit()">
      <input formControlName="email" type="email" />
      <button type="submit" [disabled]="userForm.invalid">Submit</button>
    </form>
  `
})
export class ProfileFormComponent {
  private fb = inject(NonNullableFormBuilder);

  userForm = this.fb.group({
    email: ['', [Validators.required, Validators.email]]
  });

  submit() {
    if (this.userForm.valid) {
      console.log(this.userForm.getRawValue()); // Outputs strongly typed object { email: string }
    }
  }
}

Routing & Navigation

Enable route bundles optimization via code-splitting lazy load targets:

export const routes: Routes = [{
  path: 'dashboard',
  loadComponent: () => import('./dashboard.component').then(c => c.DashboardComponent),
  canActivate: [authGuard],
  resolve: { serverData: statsResolver }
}];

4. Fixation Solutions

Exercise 1 Solution: SignalStore Implementation

import { computed, signal, Signal, WritableSignal } from '@angular/core';

export class SignalStore<T extends object> {
  private readonly _state: WritableSignal<T>;
  readonly state: Signal<T>;

  constructor(initialState: T) {
    this._state = signal<T>(initialState);
    this.state = this._state.asReadonly();
  }

  select<K>(selector: (state: T) => K): Signal<K> {
    return computed(() => selector(this._state()));
  }

  update(reducer: (state: T) => Partial): void {
    this._state.update(current => ({
      ...current,
      ...reducer(current)
    }));
  }
}

Exercise 3 Solution: Global HTTP Error Interceptor

export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const router = inject(Router);
  const alert = inject(AlertService);

  return next(req).pipe(
    catchError((error: HttpErrorResponse) => {
      if (error.status === 401) {
        alert.show('Authentication required.');
        router.navigate(['/login']);
      }
      return throwError(() => error);
    })
  );
};
